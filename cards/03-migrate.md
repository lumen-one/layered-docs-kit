# 任务卡 03：迁移一个批次

> 读取范围：本卡；派发 prompt 的「本批次」节；`docs-plan/proposal.md` 的事实归属表；`reference/layers.md` 的「一个事实一个家」「写作规则」「维护规则表」；`reference/checks.md` 的检查项 1、2、3、5。
> 前置：层级与模板已建立。
> 产出：本批次 `files` 内的文档改动、报告第 3 节列出的入站链接修复；`docs-plan/migrate/<batchId>.md`。
> 禁止：处理本批次与入站链接修复之外的文件。

## 目标

把一个批次内的文档改成新体系：去重、归属、删除过期内容、修复入站链接。每批结束时按判定方式核对通过，且改动范围可核对、可回滚。

## 步骤

1. 读派发 prompt 的「本批次」节，列出本批 `files` 与 `acceptance`。派发内容缺失时停止并回报，不要自行读 `batches.json` 或扩大范围。
2. 按事实归属表处理每个文件：
   - 重复内容：确定归属页，把完整表述移到归属页，其他位置改为一句链接。
   - 过期内容：内容级删除（段落、章节、链接）可直接执行，但必须写进报告第 2 节；文件级删除只允许在本批 `deletion` 为 `true` 且派发 prompt 的「确认记录」已填日期时执行。有历史价值的内容按档位转入决策记录，`basic` 档转入提交历史或 CHANGELOG。
   - 无归属内容：放进它所属的层，或删除。
   - 缺失内容：只补本批次范围内的必需章节，不顺手扩写其他模块。
3. 全仓搜索本批文件的被引用路径，原子修复所有入站链接。允许修改本批 `files` 之外的文件，但只允许改指向本批文件的链接目标，并在报告第 3 节逐条列出源文件、原链接、新链接。移动文件时不要留重定向。
4. 按 `checks.md` 检查项 1、2、3、5 的判定方式人工执行死链、锚点、段落内硬换行与本批涉及的结构检查；自动检查器在 `checks` 阶段实现后会对本批复跑。
5. 写 `docs-plan/migrate/<batchId>.md`。

## 报告结构

````markdown
# 批次报告：<batchId>

## 1. 范围

| 文件 | 动作（保留 / 移动 / 合并 / 删除 / 重写） | 理由 |
|---|---|---|

## 2. 删除项与替代

| 删除内容 | 原位置 | 级别（文件 / 内容） | 替代位置或「无，理由」 | 确认记录 |
|---|---|---|---|---|

## 3. 入站链接修复

| 源文件 | 原链接 | 新链接 |
|---|---|---|

## 4. 检查结果

| 检查 | 结果 | 失败项与处置 |
|---|---|---|

## 5. 范围核对

```sh
git status --short
git diff --name-only
git ls-files --others --exclude-standard
```

逐行确认都落在本批 `files`、本批报告或报告第 3 节列出的入站链接源文件内。入站链接源文件只允许改链接目标。`git diff` 只覆盖已跟踪文件，新建文件用 `git status` 与 `git ls-files --others` 核对。

## 6. 回滚

```sh
git restore -- <本批已跟踪文件与报告第 3 节列出的入站链接源文件>
# 本批新建的未跟踪文件逐个删除
```
````

## 验收

- `git status --short` 的每一行都在本批 `files`、本批报告或报告第 3 节列出的入站链接源文件内；`git diff --name-only` 与未跟踪文件均逐条核对过，报告第 5 节有记录。
- 每个删除项都有替代位置或明确的「无，理由」；文件级删除的批次 `deletion` 为 `true`，且派发 prompt 的「确认记录」已填日期。
- 死链、锚点按 `checks.md` 判定方式人工核对通过；段落内无硬换行。
- 报告的六节齐全，回滚命令已替换成本批实际文件路径，可直接执行。
- 本批 `acceptance` 逐条满足。

## 禁止

- 顺手重写其他批次或无关模块。
- 删除有外部引用的文件而不确认。
- 为了让检查变绿而删除链接或段落。
- 把多个批次堆在工作区里；一个工作区只保留一个批次的改动。

## 回报

```text
产物：<改动文件清单>、docs-plan/migrate/<batchId>.md
范围核对：<n> 个文件，全部在批次内 / 越界 <文件>
检查：死链 <通过/失败>，锚点 <通过/失败>，段落内硬换行 <通过/失败>
未决问题：<无则写「无」>
```
